# 「特徴」（ジャンル）の分類ルール

`analysis/samunet_summarize.py` の `GENRE_RULES` と同じ内容。ルールを変えたら両方を直す。
もとのルールは番組担当者から受け取ったもの。⑥⑦（アスリート・職人）と判断例は、2026-11-19 に担当者と相談して追加した。

## 判定の基準

**サムネになっている人物**（サムネに写り、サムネの文言が指している人物）で判定する。
同じ行に家族・同行者がいても、サムネの人物に当てはまらない分類は付けない。サムネが無い行は、紹介の中心になった人物で判定する。

## 分類

| 分類 | 条件 |
|---|---|
| スーパーキッズ | 一般の方のうち、スポーツや勉強に秀でた、乳幼児から大学生程度までの子ども。**今は大人でも、子ども時代（大学生程度まで）の実績が紹介の中心なら含める**。子どもを指導するコーチや親など、大人本人の実績が中心の場合は含めない。趣味・好きなもの（スポーツや勉強の実績ではないもの）は、子どもでも含めない |
| アスリート | 大人になってからのスポーツでの実績が紹介の中心（プロ選手、五輪・日本代表、実業団、全国レベルの指導者など。現役・引退は問わない）。実績が子ども時代のものなら「スーパーキッズ」 |
| 職人 | 伝統工芸・ものづくり・手仕事の技術を職業にしていることが紹介の中心（陶芸、染物、着物、靴磨き、大工など）。料理人・画家・アーティストは含めない |
| マニア | テロップ・ナレーションなどで「〇〇が好きすぎる」と紹介されている。「大好き」「〇〇愛」「〇〇にこだわる」など、熱中ぶりが紹介の柱なら含める。単に趣味や収集をしているだけでは含めない |
| フード | 特徴的な飲食店が登場する。超町人が飲食店を営んでいて店や料理が紹介されれば、紹介の主題が店以外でも付ける |

フードの追加分類（必ず「フード」と併記する）：

| 分類 | 条件 |
|---|---|
| 海鮮 | 魚介類（うなぎなど川魚も含む）、刺身、寿司、海鮮丼、海鮮料理などが主に紹介される |
| 肉 | 焼肉、ステーキ、ハンバーグ、肉料理などが主に紹介される |
| 麺 | ラーメン、うどん、そば、パスタ、焼きそばなどが主に紹介される |
| スイーツ | ケーキ、パフェ、プリン、和菓子、アイスクリーム、その他の菓子・デザートなどが主に紹介される |
| 中華 | 餃子、麻婆豆腐、チャーハン、点心、中華料理などが主に紹介される |
| デカ盛り | 料理の量やサイズが通常より著しく大きいことを、番組内で特徴として紹介している |
| 異国料理 | 日本以外の国・地域の料理が主に紹介される（中華は「中華」）。アメリカ料理の店はハンバーガーなど肉料理が出ても「異国料理」を優先する |

## 共通ルール

- 複数の条件に当てはまる場合は、該当する分類名をすべて記載する。区切りは「、」。
- 記載順は「スーパーキッズ、アスリート、職人、マニア、フード、海鮮、肉、麺、スイーツ、中華、デカ盛り、異国料理」。
- どれにも当てはまらない場合は「該当なし」。
- 料理に魚介類や肉類が材料として含まれているだけでは「海鮮」「肉」にしない。
- 「デカ盛り」は見た目だけで判断せず、大盛り・巨大サイズ・大食い向けなどの特徴が明確に紹介されている場合に限る。
- 番組内で明示されていない情報から、分類を推測しない。

並び順と「フード」の併記は、Gemini の答えをプログラム（`_normalize_genre`）で機械的にそろえている。

## 追加を検討したが見送った分類

5回分（36行）で「該当なし」になった人から候補を挙げたもの。必要になったら追加を検討する。

- 社長・起業家（3社経営の25歳社長、虫歯予防食品を開発した研究者 など）
- 夫婦・家族（夫婦・一家で出演する人が多い。線引きが難しい）
- 芸能・アート（IKEA の歌姫、元ハリウッド俳優 など）
- 海外・外国人（バングラデシュ出身の研究者、ラオスで活動した象使い など）
- おもしろキャラ（そっくりさん など。主観になりやすい）
